## 🛠 Getting Started

### Prerequisites

- Node.js 18+ 
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/css-animation-generator.git

# Navigate to project directory
cd css-animation-generator

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the animation studio.

## 📖 Usage

### Basic Animation Workflow

1. **Select a Preview Shape** - Choose from square, circle, text, button, or card
2. **Choose Background** - Pick a grid, dots, gradient, or solid background
3. **Set Basic Properties** - Configure duration, delay, timing function, and iteration count
4. **Apply Transforms** - Use sliders to adjust position, rotation, scale, and skew
5. **Add Filters** - Enhance with blur, brightness, contrast, and color effects
6. **Export CSS** - Copy the generated CSS code to your project

- **Keyframe Mode** - Create complex multi-step animations (Coming Soon)
